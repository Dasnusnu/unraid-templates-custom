# unraid-templates-custom

Custom Unraid Community Apps templates.

To use these templates, add this repository URL to your Unraid Community Apps template repositories:

```
https://github.com/dasnusnu/unraid-templates-custom
```

## Templates

| Template | Description |
|---|---|
| [PrintGuard](PrintGuard.xml) | Real-time 3D print failure detection via computer vision, with OctoPrint integration and push notifications. |
