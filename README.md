# unraid-templates-custom

Custom Unraid Community Apps templates.

To use these templates, add this repository URL in Unraid under **Docker → Settings → Template Repositories**:

```
https://github.com/dasnusnu/unraid-templates-custom
```

## Templates

| Template | Description |
|---|---|
| [KA_PrintGuard](KA_PrintGuard.xml) | Real-time 3D print failure detection via computer vision, with OctoPrint integration and push notifications. |
| [KA_HytaleServerManager](KA_HytaleServerManager.xml) | Web-based dashboard for managing Hytale game servers with real-time console, backups, mod management, and Discord notifications. |
| [KA_WindroseServer](KA_WindroseServer.xml) | Dedicated server for Windrose (Wine on Debian). Uses P2P invite-code networking — no port forwarding required. |
| [KA_WyzeBridge](KA_WyzeBridge.xml) | Local RTMP, RTSP, HLS, and WebRTC streams for Wyze cameras. Integrates with Home Assistant, Frigate, and any media player. |
